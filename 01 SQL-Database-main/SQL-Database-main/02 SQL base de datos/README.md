# 🚀 SQL base de datos with C# and SQLite

Welcome! This repository tracks my learning progress in software development, focusing on relational databases and data persistence.

📊 SQL & Relational Database Foundations
• DDL & DML Implementation: Wrote structured SQL queries utilizing Data Definition Language 
(CREATE TABLE) and Data Manipulation Language (INSERT INTO, SELECT).

• Data Integrity: Enforced basic schema constraints and understood primary keys to uniquely identify database records.

⚙️ Data Persistence & C# Connectivity
• Dynamic Database Initialization: Implemented logic to automatically check, create, and initialize local .db files at runtime if they do not exist.

• Connection Lifecycle Management: Managed secure, local database sessions, ensuring proper opening and closing of data streams to prevent resource leaks.

• File-Based Persistence: Configured explicit connection strings to guarantee data survives application restarts on the hard drive.
