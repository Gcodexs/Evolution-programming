# 🛒 C# & SQL Concepts Learned — E-Commerce System
ddas
This project was developed with **C# and .NET** as a practical exercise to understand how a backend application communicates with a **SQL Server relational database**.

The main objective was to build a foundation for working with **data persistence, database operations, and API communication** in a backend environment.

## 🛠️ Technologies & Concepts Used

* **C# / .NET** — Application and backend development.
* **ASP.NET Core** — Building the backend API.
* **Entity Framework Core** — Connecting the C# application with SQL Server through an ORM.
* **SQL Server** — Relational database used for data persistence.
* **LINQ** — Querying and filtering data from the application.
* **CRUD** — Creating, reading, updating, and deleting records.
* **Database Migrations** — Keeping the application models and database structure synchronized.
* **Dependency Injection** — Providing required services and dependencies to application components.
* **REST API** — Exposing backend functionality through HTTP endpoints.

## 🔄 How the Application Works

The project helped me understand how the different components work together:

**Client → API → Controller → Entity Framework Core → SQL Server**

A client sends a request to the API. The backend processes the request, Entity Framework Core communicates with SQL Server, and the result is returned to the client, typically as **JSON**.

## 🎯 What I Learned

Through this project, I gained practical experience understanding how **C# application logic, backend APIs, ORM technology, and relational databases work together as a complete system**.

The project also helped me become familiar with concepts that are commonly used in real-world .NET backend development, such as **CRUD operations, LINQ, migrations, dependency injection, REST APIs, and database persistence**.
